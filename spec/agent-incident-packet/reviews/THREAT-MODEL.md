# Agent Incident Packet v0.1 threat model

**Profile:** `glyph.agent-incident-packet/0.1-draft`

**Maturity:** experimental, source-only, team-operated
**Review date:** 2026-07-26

The verifier treats the packet directory, every carried byte, every declared
role, and every packet-carried root as untrusted. Trust inputs come from the
separate verification context. Coverage gaps are findings rather than packet
integrity failures.

| Threat | Required mechanism | Regression test | Residual limitation |
|---|---|---|---|
| Duplicate JSON members alter parser interpretation | Byte-level parsers reject duplicate members before validation | `test_packet_core_strict_ingestion_matches_standalone_checkers` | The profile covers JSON members, not ambiguity in opaque trace formats |
| Excessive files, bytes, depth, nodes, or strings exhaust the verifier | Per-file, aggregate, count, depth, node, and string limits | `test_packet_core_resource_limit_precedes_verification`; `test_packet_file_count_and_aggregate_limits` | Limits are implementation policy and may require revision for larger legitimate incidents |
| Symlinks or traversal escape the packet root | Normalized POSIX paths, no symlinks, regular-file descriptor reads, declared-file closure | `test_symlink_and_undeclared_file_are_rejected`; `test_unsafe_manifest_path_is_rejected_before_file_access` | Python uses descriptor-relative no-follow traversal. Node uses no-follow final-member opens and inode checks; portable Node built-ins do not provide a complete `openat` directory walk on every supported platform |
| An artifact or receipt file changes after publication | Exact byte length and SHA-256 commitments, signed packet-core hash | `test_tampering_fails_closed_and_suppresses_dependent_claims` | Hashes establish byte identity, not factual truth |
| A receipt field or proof is modified | ActionReceipt v0.4 hash and Ed25519 proof recomputation | `test_tampering_fails_closed_and_suppresses_dependent_claims`; `test_unsigned_or_transplanted_boundary_proofs_fail` | Compromise of an accepted signing key remains a relying-party concern |
| A proof is transplanted across purpose, run, action, or packet | Domain-separated content, occurrence, authorization, and checkpoint proofs; closed action subjects | `test_unsigned_or_transplanted_boundary_proofs_fail`; `test_resigned_semantic_and_binding_mutations_match_all_checkers` | Signatures do not establish that a worldly action occurred |
| Packet-carried identities bootstrap their own trust | Role issuers and witness roots must match an external context; a key cannot occupy two incident roles | `test_packet_roles_do_not_bootstrap_trust`; `test_context_rejects_cross_role_issuer_collision` | The verifier does not resolve enterprise identity systems or revocation |
| An observation is grafted onto the wrong decision, phase, or run | Accepted prior permit, exact mandate, request, run, protocol, action type, and ordered lineage | `test_resigned_semantic_and_binding_mutations_match_all_checkers`; `test_cross_phase_action_type_transplant_fails_closed` | The profile checks recorded lineage, not hidden actions |
| A downstream action uses an unrelated mandate | Accepted prior mandate plus exact run, policy, validity-window, and parent bindings | `test_effect_anchor_distinguishes_uncovered_from_empty_denominator` (`cross_run` and `cross_policy`) | The verifier does not establish that the mandate policy was substantively adequate |
| A handoff omits, reorders, or anticipates evidence | Exact ordered named prior statements and exact complete prior timeline parents | `test_handoff_requires_exact_ordered_reference_sets`; `test_handoff_cannot_name_a_future_statement` | Exact references preserve the declared record; they do not establish factual agreement |
| A duplicate or malformed denominator inflates coverage | Unique identifiers and exact anchor, phase, protocol, run, and projection validation; invalid groups become `NOT_COMPUTED` | `test_duplicate_denominator_ids_make_coverage_not_computed`; `test_hostile_denominator_mutations_never_preserve_declared_coverage` | An empty declared observation set is explicitly `NOT_COMPUTED`, not vacuous `0/0` coverage |
| A publisher removes an entire decision or effect denominator | Every represented protocol requires exactly one decision anchor and one effect anchor, with a matching coverage report | `test_protocol_requires_one_decision_and_one_effect_anchor`; `test_packet_without_a_denominator_is_malformed` | The closed profile covers HTTP and MCP only |
| A publisher shortens an effect denominator to erase a bypass | Each denominator is bound to an earlier accepted role-constrained statement over the exact denominator bytes | `test_publisher_alone_cannot_republish_a_self_shortened_denominator` | An accepted path-separated observer can still issue a shorter signed denominator. Team-controlled role separation is not organizational independence or proof of completeness |
| Duplicate or conflicting receipts erase an uncovered event | Duplicate projections invalidate every conflicting candidate | `test_pilot_duplicate_receipts_cannot_cover_an_observation` | Coverage detects omissions only within the supplied denominator |
| A declared coverage report differs from recomputation | Exact closed report equality and Boolean-safe integer validation | `test_coverage_boolean_cannot_coerce_to_integer` | An uncovered event remains a completed result, not an integrity failure |
| A packet claims witness inclusion from an unsigned list | Signed checkpoint hash and proof, accepted witness role, and externally trusted root are required | `test_signed_witness_mutations_fail_closed` | A team-operated witness is not organizationally independent; v0.1 permits at most one witness reference and leaves multiple-witness aggregation unresolved |
| Actor time is promoted to witnessed or externally anchored time | `claimed_at`, `received_at`, `witnessed_at`, and `anchored_before` remain separate; actor timestamps cannot populate witness labels | `test_actor_claimed_time_cannot_promote_itself_to_witness_time`; `test_signed_witness_mutations_fail_closed` (`anchored_before`) | Clock accuracy is not established without separately verified external time evidence |
| A publisher rewrites a redaction record without reviewer participation | The released redaction record exactly binds source/release hashes, tool/version, rules, and `NOT_COMPUTED`; an accepted reviewer statement binds only that record hash | `test_publisher_alone_cannot_rebind_a_redaction_record` | Byte binding does not determine whether transformation rules are adequate or disclosure is safe |
| A non-counterparty labels its statement counterparty-confirmed | The closed profile permits that status only for the accepted `affected_party` role | `test_resigned_semantic_and_binding_mutations_match_all_checkers` | Role acceptance does not establish the truth of the statement |
| Conflicting statements or corrections are silently collapsed | Signed party statements remain separate; topic conflicts and correction forks are reported without selecting by actor time | `test_conflicting_correction_fork_is_preserved_without_actor_time_selection`; clean vectors require the `effect-coverage` conflict | The verifier does not adjudicate which party is correct |
| A correction relabels statement hashes as packet references or names a future/unreleased target | Statement corrections resolve to prior named statements; packet corrections resolve to distinct released packet-core artifacts | `test_resigned_semantic_and_binding_mutations_match_all_checkers` | A released packet-core artifact proves content resolution, not its separate publication proof |
| Verification exfiltrates evidence | Verification performs no network access | `test_verification_is_offline` | Operating-system and runtime integrity remain outside the packet |
| Public fixtures contain secrets, host paths, or private reasoning | Synthetic fixed data, controlled source artifact omitted, recursive heuristic scan | `test_public_packet_has_no_heuristic_privacy_findings`; `test_privacy_detector_catches_nested_and_derived_material` | Heuristics can miss novel encodings, context-dependent data, and secrets outside the fixed low-entropy dictionary; disclosure safety remains `NOT_COMPUTED` |
| A pilot writes outside its assigned output | New output directory, no-follow/exclusive files, fixed child paths | `test_live_pilot_requires_a_new_output_directory` plus pilot path-escape regression | The pilot remains local demonstration code, not a hardened multi-tenant service |
| A pilot coverage summary accepts an ID-only or repeatedly duplicated match | Exact seven-field observation projection, persistent duplicate tombstones, and attestation/role validation | `test_pilot_coverage_uses_decision_event_id_and_exact_projection`; `test_pilot_duplicate_receipts_cannot_cover_an_observation` | The adapter binds retained bytes but does not define universal HTTP or MCP semantics |
| Malformed pilot requests create receipts or effects | Duplicate-aware JSON and bounded HTTP/MCP reads reject before logging or dispatch | `test_http_boundary_rejects_duplicate_and_oversized_json_without_records`; `test_mcp_boundary_rejects_hostile_lines_without_records` | These fixed pilots are not general-purpose gateways |
| A pilot helper is redirected to an external or credential-bearing destination | HTTP accepts only canonical literal-loopback `/act` or `/effect`; MCP accepts only an explicit bounded port and always calls literal loopback | `test_http_helper_rejects_non_closed_destination_before_connect`; `test_mcp_helper_rejects_invalid_port_before_connect` | The regression proves rejection before the project opener/socket call; it is not an operating-system firewall |
| An effect occurs but observation-receipt persistence fails | The target denominator is separate from the boundary and the missing receipt remains uncovered | `test_effect_anchor_distinguishes_uncovered_from_empty_denominator` (`uncovered-effect`) | An accepted observer can still omit a row; the result is team-operated evidence, not independent completeness |
