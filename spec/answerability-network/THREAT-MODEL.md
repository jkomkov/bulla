# Answerability Network threat model

The combined Answerability Network, Witness Covenant, and Reliance Map hostile
corpus covers altered procurement lineage, opaque or missing delivery evidence,
stronger evidence labels, wrong provider selection, wrong pre-action covenant,
borrowed receipt inclusion, invalid or
withheld checkpoint views, different operator/log/epoch/size, packet-carried
trust substitution, graph-root substitution, forged recall paths, cross-graph
replay, incomplete-lineage clearance, open-challenge authorization, wrong bond
or destination, P3 auto-recourse, report type coercion, archive paths,
symlinks, resource limits, malformed nonnormative projections, and Test-ledger
language presented as real funds.
The focused CI runs all three suites; the composition profile does not relabel
inherited guards as newly independent evidence.

Residual risks include missing real-world actions, undisclosed dependencies,
compromised accepted trust roots, organizational collusion, unavailable
challenge or settlement roles, custody failure, and non-collection.
