# Reliance Map 0.1 preregistration

## Primary question

Can three separately executed kernels agree on exact descendants of an
authenticated correction in a 10,000-decision declared dependency graph while
refusing forged authority, incomplete-lineage clearance, graph substitution,
and path fabrication?

## Frozen primary result

The generated corpus contains exactly 10,000 `RELIANCE` decisions in four
disjoint finite trees. Correcting the accepted source of lane 0 must yield:

- 2,500 `AFFECTED` decisions with replayable paths;
- 5,000 `NOT_AFFECTED` decisions in complete unrelated lanes; and
- 2,500 `UNDETERMINED` decisions below the deliberately incomplete lane 2.

Python, standalone Node, and the browser must deep-equal on every report field.
The browser projection has a separate root and is not normative evidence.

## Kill conditions

Narrow or withdraw the public behavior claim if any accepted implementation:

- clears incomplete ancestry as `NOT_AFFECTED`;
- accepts a packet-carried graph or correction authority not named externally;
- reports an affected result without an exact replayable path;
- changes semantic results because node or edge input order changes;
- treats recall as rollback, truth, safety, or consequence authority; or
- disagrees with another kernel on a protected field.

## Non-claims

The corpus is constructed. It supplies no evidence of real adoption, complete
worldly dependencies, correction truth, organizational independence, rollback,
or production operation.
