# One-action shadow integration packet

Choose one real consequential action owned by a nonlocal team. Receipt it in
shadow mode, compare the artifact with existing logs, and record all available
answerability dimensions. No receipt gates production, settles value, changes
authority, or implies a safety certification.

Return integration hours, semantic-modeling decisions, missing observables,
documentation ambiguities, grounding residue, and whether a second person on
the team found the artifact useful. Do not transmit secrets or personal data.
The result measures integration cost and local usefulness only.
